01 / Connection

Connect Earth Engine

Not connected
One-time setup — about five minutes, and you only do it once

This page has no server and no credentials of its own: it runs on your Google account and your Earth Engine project. The two fields above are yours to fill in once; the browser remembers them afterwards. Each step below links to the exact console page it refers to.

  1. Create or pick a Google Cloud project. console.cloud.google.com/projectcreate ↗
    Copy its project ID — the lowercase one, not the display name — into Google Cloud project above.
  2. Register that project for Earth Engine. code.earthengine.google.com/register ↗
    Pick noncommercial use if you qualify. Earth Engine access belongs to the project, not to your account, so this has to be the same project as step 1.
  3. Enable the Earth Engine API in it. API library → Earth Engine API ↗
  4. Set up the consent screen. Google Auth Platform → Overview ↗
    If the page says "Google Auth platform not configured yet", press Get Started and fill in an app name, a support email, an audience and a contact email. Do this first — until it is done the Audience and Clients pages in the next two steps do not exist, which is the usual reason they cannot be found. For audience pick External, unless your account is in a Google Workspace organisation and everyone using this page is too.
    In the console's menu this lives under Google Auth Platform. It used to be APIs & Services → OAuth consent screen, which is gone; guides still naming it are out of date.
  5. Add yourself as a test user, and stay in Testing. Google Auth Platform → Audience ↗
    Under Test users press Add users and enter the Google account you will sign in with. Miss this and Google answers "has not completed the Google verification process" instead of signing you in. Leave publishing status at Testing: publishing a sensitive scope triggers a manual review that takes weeks and buys nothing here. (An Internal audience has no test-user list and needs none.)
  6. Create an OAuth client of type Web application. Clients → Create client ↗
    Under Authorized JavaScript origins add exactly this page's origin — scheme and host, no path, no trailing slash. This is the step that is usually wrong: without it Google refuses the sign-in.
  7. Paste the client ID into the second field above. It is the value ending .apps.googleusercontent.com.
    A client ID is public configuration and is meant to be visible. Never paste the client secret (it starts GOCSPX-) or a service-account key — this page uses neither.
  8. Press Connect Google account.
    The one permission requested is earthengine.readonly. Earth Engine bills the pixel computation to the project you named; the model runs in this browser, and no imagery or result is uploaded anywhere.
